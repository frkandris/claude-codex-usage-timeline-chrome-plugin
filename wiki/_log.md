## 2026-09-05
* A review pass against Google's code-review standard (google.github.io/eng-practices) and Fowler's smell/self-testing guidance turned up one real defect and two structural fixes: `codex review --uncommitted` (gpt-6-astra) found that a first collection finishing *after* someone saved the settings page would roll their provider switches back, so `collectUsage` now re-reads the settings after collecting and `firstRunProviderSettings` owns the whole "is this still the first run" rule; the chart range vocabulary moved from `dashboard/dashboard.js` into the tested `lib/settings.js` (`RANGE_DURATIONS_MS`, `normalizeRange`); and two drift-guard tests now assert the HTML dropdowns offer exactly the values the code knows. [[2026-09-05-first-run-provider-detection]] rewritten around the re-read, [[development-and-testing]], [[architecture]], [[background-service-worker]] and [[dashboard]] updated. Tests: 38 → 46.
* Chart range dropdown now steps a day at a time: `24 hours`/`48 hours` became `1 day`/`2 days` and `3`–`6 days` were added between them and the existing `7 days`. Day options are bare-number keys in `rangeDurations`, and `normalizeRange` (`dashboard/dashboard.js`) aliases the retired `48h` key to `2` so a stored selection survives. [[dashboard]] updated.
* A brand-new install now decides its own providers: the first collection that reads anything switches off the provider that answered nothing and moves the badge to the survivor (Claude → Codex), guarded by a one-way `providersInitialized` flag that a settings save or an extension update also sets. New decision page [[2026-09-05-first-run-provider-detection]]; [[settings]], [[background-service-worker]], [[toolbar-badge]] and [[glossary]] updated. New pure helpers `firstRunProviderSettings` (`lib/settings.js`) and `hasReading` (`lib/usage.js`). Tests: 34 → 38.
* Dashboard provider headings became links to the providers' own usage pages (`claude.ai/settings/usage`, `chatgpt.com/codex/settings/usage` — both verified live on 2026-09-05 to redirect to the panel showing the same numbers), and a small [[chrome-web-store]] listing link was added in a new footer; [[chrome-web-store]] now records the public listing URL and its truncated `…-claud` slug.
